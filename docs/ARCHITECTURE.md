# V4 架构

首帧 RGB 和指定目标框建立固定 LoRAT 模板、模板标记及首帧参考。

每个新图像时刻先从当前可信位置或暂定位置做 LoRAT 局部定位，再同步运行同一 RGB 的 YOLO 全图检测。活动检测框与上一帧关联成短期分支，并独立调用固定模板 LoRAT 定位。重合局部候选可复用结果。

局部和全局提议共用 `SharedReferenceVerifier`：正向数值有效且响应不低于 0.5，然后以当前候选裁剪为临时模板，在首帧初始框附近定位。反向响应要求至少 0.5，预测框与首帧初始框 IoU 至少 0.3。验证使用相同 LoRAT 权重，不训练，不覆盖实际首帧模板。

通过检查的提议按空间分组。正常 TRACKING 中局部提议处于唯一组时立即提交；进入不确定状态后的重新确认需要同一分支的唯一证据连续 3 帧。多个空间组保留歧义。

当前输出与可信位置写入分开：确认则输出且提交；未确认但局部框数值有效时仍输出局部暂定框，仅推进暂定位置；局部无效但存在唯一候选组时可输出候选暂定框；没有可用框才输出空结果。空结果不等于物理离场。

当前没有语言输入、学习式时序模块或独立实例重识别网络。候选 ID 是几何关联编号，不是真实身份标签。详细原始架构记录见 `FRAMEWORK_V4_historical.md`，其中“全量尚未建立”是当时记录，不是当前完成状态。
