# LoRAT B C 开发验证结果

所有结果来自 Train 内固定划分的 132 条完整开发验证序列，共 47200 帧。该划分此前用于 YOLO 选权重；本轮没有运行 Test420。以下是单种子、固定训练预算的首轮结果，不能视为稳定收益或盲测结论。

| 版本 | AUC | P20 | NP AUC | mACC | 在线 FPS |
| --- | ---: | ---: | ---: | ---: | ---: |
| A | 72.369 | 86.999 | 79.343 | 73.767 | 39.87 |
| B | 74.376 | 87.341 | 80.135 | 75.854 | 40.75 |
| B_POOL | 74.376 | 87.341 | 80.135 | 75.854 | 37.67 |
| C | 74.522 | 87.299 | 80.257 | 76.003 | 35.86 |

A 为原始权重的 V3 输出分离基线；B 为 UAV 微调；B_POOL 增加与 C 相同构造方式的候选池及特征提取，但保留 B 的选择与状态；C 使用学习比较、未匹配输出和连续确认后的搜索位置替换。B_POOL 与 B 的全部预测文件已通过逐文件一致性检查。C 改变跟踪轨迹，因此两者后续帧的实际候选数值可能不同。

## 配对变化

| 比较 | AUC 变化百分点 | 按序列 Bootstrap 95% 区间 | 更好 更差 持平 |
| --- | ---: | --- | --- |
| B_minus_A | +2.007 | [+1.423, +2.596] | 112 / 19 / 1 |
| C_minus_B_POOL | +0.145 | [-0.583, +0.890] | 33 / 28 / 71 |
| C_minus_A | +2.153 | [+1.308, +2.998] | 109 / 23 / 0 |

B 的开发验证 AUC 变化为 +2.007 个百分点；C 相对 B_POOL 的变化为 +0.145 个百分点。区间跨零表示当前序列样本未提供明确的平均收益证据。区间只反映按序列重采样的不确定性，未覆盖训练种子和视频共同来源的影响。

## 诊断与复查

各版本 SUMMARY.json 同时提供微小目标命中、严重偏移、重现后连续三帧命中、候选池覆盖、存在正确候选时仍未匹配或选错、全局提交命中等诊断。它们用于区分表征、候选覆盖和选择失败；不能把几何关联标签当作人工身份标注。

完整数值：[COMPARISON.json](/home/xu/zyx/send/LORAT_BC_R1_20261003/comparison/COMPARISON.json)。逐序列指标与完整逐帧轨迹位于各版本 validation 目录。原 V4 权重与结果未被替换，当前脚本不会自动晋升新模型。

指标调用已安装的官方 MMOT 函数，主指标含第一帧 GT 初始化；可见帧诊断排除第一帧。在线 FPS 包含逐帧同步 YOLO、候选探测与比较头，不含图像读取和模型启动。
