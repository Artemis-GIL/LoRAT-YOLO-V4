# B+D 与 V4 的完整 Test420 对比

两组均完成 **420 条、476221 帧**，使用相同的 V4 对齐 JPEG 列表、GT 初始化和官方 MMOT 计分函数。B+D 的 AUC 点估计比 V4 高 0.647 个百分点，但序列配对区间跨零；NP AUC、P20 和可见命中率的提升区间均为正。不能将整套版本间的差异全部归因于时序模块。

| 指标（序列宏平均） | V4 | B+D | 差值（百分点） | 95% 配对区间（百分点） |
|---|---:|---:|---:|---:|
| AUC | 48.829% | 49.476% | +0.647 | [-0.955, +2.210] |
| Precision20 | 64.255% | 67.560% | +3.305 | [+1.110, +5.419] |
| cAUC | 48.485% | 49.214% | +0.729 | [-0.869, +2.294] |
| nPrecision_at_0_2 | 59.481% | 63.451% | +3.970 | [+1.877, +5.984] |
| nPrecision_AUC | 54.501% | 57.883% | +3.383 | [+1.528, +5.178] |
| mACC | 49.619% | 50.240% | +0.620 | [-1.013, +2.218] |
| visible_mean_iou | 55.367% | 56.645% | +1.278 | [-0.577, +3.084] |
| visible_hit50 | 64.881% | 69.521% | +4.640 | [+2.333, +6.865] |

AUC 在 193 条上升、226 条下降、1 条相同；NP AUC 为 289 / 130 / 1。这里覆盖全部序列，没有按个别序列挑选结论。

区间由 20000 次序列配对 bootstrap 得到（固定种子 20261004，百分位法）。每次抽样以完整序列为单位，避免将强相关的视频帧当成独立样本；这些区间不覆盖训练随机种子差异，也没有做多指标检验校正。

## 可比性核验与边界

- 420 个序列名称、各自帧数和可见帧数完全相同；逐序列指标重聚合与两份 SUMMARY 一致。
- B+D 的 PREPARATION 明确复用 V4 INPUTS；当前输入清单与冻结 SHA 一致，记录的 JPEG stat-inventory 摘要一致。本脚本未重新解码全部图像。
- 两组冻结清单中的 65 个 MMOT 源文件、840 个 GT/absent 文件完全同摘要，并与当前文件相符。两组调用同一 `tracking.test420_v4.score_arrays`，其源文件摘要一致。
- 主指标包含 GT 初始化首帧，可见诊断排除首帧；两组无空输出，四数值框导出和 mACC 口径一致。
- B+D 由先前 Val132 选择，Test 不参与选择；本次只读现有结果，没有运行模型、改阈值或重新选择。
- V4→B+D 同时包含结构策略、关闭反向验证、LoRAT 的 UAV 微调、候选计算和 GRU-D。缺少同一 Test420 上的 B-only、D0 消融，不能将 +0.647 pp AUC 或 +3.383 pp NP AUC 全算作时序收益。时序单因素证据仍是此前 Val132 的 D−D0。
- 物理缺席判别仍关闭；自动恢复和全局提交不代表身份已经被保证。
